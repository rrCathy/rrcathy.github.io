怎么读这篇。 正文是一条写给初学者的主线，只需要「排列」和「乘在一起」那点直觉。文中会不时冒出一个写着「展开细节」的折叠方块，里面放证明、伪代码和生成函数，赶时间可以全部跳过，不影响主线。

事情的起点小得不能再小。我想枚举 nnn 个元素的全排列，课本给的答案是递归或回溯。然后脑子里冒出个念头：nnn 个元素的全排列，不就是对称群 SnS_nSn​ 的元素吗？那只要拿它的生成元，把所有元素生成出来，再映到排列上，不就行了？

这个念头看起来只是换个说法，但顺着它往下问了三次，三次都撞出新东西。这篇写的就是这三次。

一、全排列就是 Sₙ 的元素

先说清楚这个等式从哪来。三个元素 {1,2,3}\{1,2,3\}{1,2,3} 的全排列有 3!=63!=63!=6 个。但换个角度看，一个排列不是「一列数」，而是一个动作：它规定 111 去哪、222 去哪、333 去哪。比如 [2,3,1][2,3,1][2,3,1] 这个排列，说的是 1→21\to21→2、2→32\to32→3、3→13\to13→1。这种「重新安排三个位置」的动作，数学上叫置换。

三个元素的全部置换一共 6 个，它们彼此能复合（先做一个再做另一个，结果还是这 6 个之一）、能撤销、有恒等。于是它们构成一个群，叫对称群 S3S_3S3​。下面这张图摊开的就是这 6 个元素，每个标签是一段循环记号，悬停能看它把数字送到哪。

「枚举全排列」和「枚举 SnS_nSn​ 的元素」，是同一件事的两种说法。差别在于，群论手上多了一套工具，其中最关键的一件叫生成元。

S3S_3S3​ 有 6 个元素，但不用一个个列。取两个就够：s1=(12)s_1=(12)s1​=(12) 和 s2=(23)s_2=(23)s2​=(23)，也就是「交换前两个位置」和「交换后两个位置」。任何排列都能由它们复合出来，比如 (123)=(12)(23)(123)=(12)(23)(123)=(12)(23)，(13)=(12)(23)(12)(13)=(12)(23)(12)(13)=(12)(23)(12)。这两个元素生成整个 S3S_3S3​，这就是「生成元」的意思。SnS_nSn​ 也一样，所有相邻对换 si=(i i+1)s_i=(i\ i{+}1)si​=(i i+1)，i=1,…,n−1i=1,\dots,n-1i=1,…,n−1，合起来生成整个 SnS_nSn​。

先约定「乘在一起」读哪边。本文的乘积从右往左读，跟函数复合 f(g(x))f(g(x))f(g(x)) 一个读法，右边的先作用。(12)(23)(12)(23)(12)(23) 就是先交换 2,32,32,3、再交换 1,21,21,2，乘出来是 (123)(123)(123)。这几行约定后面处处要用的验算都靠它，值得先立住。

▸ (12)(23) 是怎么乘出 (123) 的

把每个数字跟一遍。(12)(12)(12) 交换 1 和 2，其余不动；(23)(23)(23) 交换 2 和 3，其余不动。

  • 1：右边的 (23)(23)(23) 不动它，左边的 (12)(12)(12) 把它送到 2，所以 1→21\to21→2；
  • 2：(23)(23)(23) 把它送到 3，(12)(12)(12) 不动 3，所以 2→32\to32→3；
  • 3：(23)(23)(23) 把它送到 2，(12)(12)(12) 把 2 送到 1，所以 3→13\to13→1。

三个数转成一圈，这就是 (123)(123)(123)。

顺序反过来写成 (23)(12)(23)(12)(23)(12)，先作用 (12)(12)(12) 再作用 (23)(23)(23)，乘出来是 (132)(132)(132)，和 (123)(123)(123) 不是一个元素。交换前两个和交换后两个，谁先谁后结果不同，这是 S3S_3S3​ 不交换的最小实例。

顺带把两种记法对上。一个置换可以写成一行数 [σ(1),σ(2),σ(3)][\sigma(1),\sigma(2),\sigma(3)][σ(1),σ(2),σ(3)]，直接列出每个数字被送到哪：[2,3,1][2,3,1][2,3,1] 就是 1→21\to21→2、2→32\to32→3、3→13\to13→1，也就是 (123)(123)(123)；[3,2,1][3,2,1][3,2,1] 是 1→31\to31→3、2→22\to22→2、3→13\to13→1，也就是 (13)(13)(13)。第四节数逆序数用的就是这行数。

于是最初那个念头有了具体的形：从恒等排列出发，不断乘生成元，把整个群撑开。

二、第一跳：用生成元撑开 Sₙ

这一步在数学上完全成立。从单位元 eee 出发，乘 s1s_1s1​ 得到 (12)(12)(12)，再乘 s2s_2s2​ 得到 (123)(123)(123)，再乘 s1s_1s1​……滚雪球一样，迟早滚出全部元素。这件事的几何图景，是下面这张凯莱图：节点是元素，边是「乘一个生成元」。

生成元撑开群，落在图上就是广度优先搜索：从 eee 出发沿着边走，能走到每一个节点。

所以最初方案的正确写法是：BFS 加一个 visited 集合判重。代码不难，难在代价。拿 (13)(13)(13) 看，从 eee 出发，s1s2s1s_1s_2s_1s1​s2​s1​ 和 s2s1s2s_2s_1s_2s2​s1​s2​ 两条路都到它，同一个元素会被当成两个来数。不判重，路越走越多，而元素总共只有 n!n!n! 个，雪球永远停不下来。判重的办法是把到过的置换都存住，一个 nnn 元置换占 O(n)O(n)O(n) 空间，存 n!n!n! 个就是 O(n!⋅n)O(n!\cdot n)O(n!⋅n)。

对比一下回溯法。时间上两者都是 O(n!⋅n)O(n!\cdot n)O(n!⋅n)，这是输出规模的下界，谁也逃不掉；但回溯法只要 O(n)O(n)O(n) 的栈，还能流式地产出每个排列，用到哪个算哪个。所以朴素闭包在这个具体问题上不占优。

朴素闭包卡住了，但卡住的地方把下一步指了出来：既然存历史太贵，那就找一条根本不用存历史的走法，让每个新排列都从前一个直接变出来。

三、第二跳：不重复地走一遍

能不能找到一个序列，让每个新排列都是前一个乘一个生成元得到的，而且全程不重复？

这等于在 SnS_nSn​ 的凯莱图上找一条哈密顿路径，访问每个节点恰好一次。对相邻对换这组生成元，这个问题有现成的答案。

Steinhaus–Johnson–Trotter 算法（1963）：给每个元素配一个箭头，每步挑「最大的可动元素」和它箭头指向的邻居交换一步，再把所有比它大的元素的箭头反转。可动的意思是，箭头指向的邻居比自己小，或者已经指到墙外。手工跑一遍 n=3n=3n=3（初始箭头全向左）：

123
132       3 向左
312       3 向左，到墙
321       2 向左，之后 3 的箭头反转
231       3 向右（箭头已反转，指向 2）
213       3 向右。没有可动的元素了，结束

6 个排列，无重复，而且每一步只交换相邻两个位置。用 S3S_3S3​ 的循环记号写出来，这条序列是

e, (23), (132), (13), (123), (12),e,\ (23),\ (132),\ (13),\ (123),\ (12),e, (23), (132), (13), (123), (12),

正好沿凯莱图的六边形绕一圈。最后一个 (12)(12)(12) 再乘一次 (12)(12)(12) 就回到 eee，所以它不止是哈密顿路径，还是一条哈密顿回路。

Heap 算法（1963）是同一件事的另一种走法，每步也交换一次，但不必相邻。它通常是最快的纯排列生成器。两个算法的伪代码都收在下面。

▸ SJT 与 Heap 的伪代码

SJT，找最大的可动元素，每步一次相邻交换：

a = list(range(1, n+1))
dir = [-1] * n                 # -1 向左, +1 向右
while True:
    output(a)
    m = None                   # 最大的可动元素
    for i in range(n):
        j = i + dir[a[i]-1]
        if 0 <= j < n and a[j] < a[i]:
            if m is None or a[i] > a[m]:
                m = i
    if m is None:
        break
    i, j = m, m + dir[a[m]-1]
    a[i], a[j] = a[j], a[i]    # 一步相邻交换
    for x in range(a[j]+1, n+1):  # 比它大的全部反向
        dir[x-1] *= -1

Heap，递归版，用计数器数组也能写成迭代：

def heap(k, a):               # 生成 a[0..k-1] 的全排列
    if k == 1:
        output(a)
        return
    heap(k-1, a)
    for i in range(k-1):
        if k % 2 == 0:
            swap(a[i], a[k-1])
        else:
            swap(a[0], a[k-1])
        heap(k-1, a)

两个算法每步都只做一次交换，O(1)O(1)O(1) 额外状态换一个排列，没有 visited 集合，没有 O(n!)O(n!)O(n!) 内存。第二跳要的就是这个。

到这里，最初那个「生成元遍历」的念头，被推进成了 1963 年数学家做出来的最优算法。而它的根可以再往前追：英国教堂的敲钟人从 17 世纪就在敲一套叫 plain changes 的排法，规矩就是每换一套钟声只交换相邻两只钟，靠这套规矩敲遍所有排列、不重不漏。把它写成数学证明和算法，是 1963 年的事。同一个结构，敲钟人、数学家、写代码的人各自撞上过。

四、第三跳：给元素分层

第二跳之后，我又多想了一层。取相邻对换做生成集时，SnS_nSn​ 的每个元素都能写成一串生成元的乘积。写法不唯一，但最短那串的长度是唯一的。那就给每个元素记一个数：把它写成生成元乘积，最少需要几个生成元。eee 是 0，生成元本身是 1，(13)(13)(13) 要 s1s2s1s_1s_2s_1s1​s2​s1​ 三次，是 3。

这个数容易和数学里现成的「阶」混淆。阶指的是最小的 kkk 使 σk=e\sigma^k=eσk=e：(123)(123)(123) 连乘 3 次回到 eee，阶是 3，但它的字长只有 2。两个量经常对不上，混用会出乱子，所以后者有自己的名字，叫字长，记作 ℓ(σ)\ell(\sigma)ℓ(σ)。放在凯莱图上看，字长就是 σ\sigmaσ 到单位元的距离。

这个数还有另一个算法，不用乘生成元：

ℓ(σ)=σ 的逆序数\ell(\sigma) = \sigma \text{ 的逆序数}ℓ(σ)=σ 的逆序数

逆序数就是 #{ i<j:σ(i)>σ(j) }\#\{\,i<j : \sigma(i)>\sigma(j)\,\}#{i<j:σ(i)>σ(j)}，数一数排列里有几对「大的排在小的前面」。拿 (13)(13)(13) 看，它写成一行数是 [3,2,1][3,2,1][3,2,1]，逆序对有三对：3 压着 2，3 压着 1，2 压着 1，逆序数是 3。证明只靠两件事，收在折叠块里，不影响主线往下读。

▸ 为什么字长恰好等于逆序数？

两个方向各证一半，夹死。

下界：每步交换相邻位置，最多改变这一对相邻元素的大小关系，所以逆序数每一步最多 ±1\pm 1±1。要走 ℓ\ellℓ 步，逆序数最多变化 ℓ\ellℓ，于是 ℓ(σ)≥inv(σ)\ell(\sigma)\ge \mathrm{inv}(\sigma)ℓ(σ)≥inv(σ)。

上界：冒泡排序能把任何排列排成有序，而冒泡的每一步就是交换一对相邻元素，恰好每次消掉一个逆序。冒泡给了具体的 inv(σ)\mathrm{inv}(\sigma)inv(σ) 步方案，于是 ℓ(σ)≤inv(σ)\ell(\sigma)\le \mathrm{inv}(\sigma)ℓ(σ)≤inv(σ)。

两边夹住，等号成立。

字长还有个立竿见影的用处：验算。写草稿时我顺手把 (13)(13)(13) 写成 (12)(23)(12)(23)(12)(23)，心想字长是 2。按「右边的先作用」跟一遍：(23)(23)(23) 把 2 送到 3、把 3 送到 2，(12)(12)(12) 再把 1 送到 2、把 2 送到 1，合起来三个数转成一圈，乘出来是 (123)(123)(123)，不是 (13)(13)(13)。(13)(13)(13) 的最短写法要三次相邻对换，比如 (12)(23)(12)(12)(23)(12)(12)(23)(12)，字长是 3。再拿逆序数验一遍：[3,2,1][3,2,1][3,2,1] 有三个逆序对，3 对 3，两边对上了。这个笔误就是逆序数抓出来的，不数一遍，字长 2 就留在稿子里了。

顺带一提，(12)(23)(12)(12)(23)(12)(12)(23)(12) 不是 (13)(13)(13) 唯一的最短写法，(23)(12)(23)(23)(12)(23)(23)(12)(23) 也是三次、也乘出 (13)(13)(13)。两条不同的最短写法相等，s1s2s1=s2s1s2s_1s_2s_1=s_2s_1s_2s1​s2​s1​=s2​s1​s2​，这条等式有个名字叫辫子关系，第六节的路牌会再遇到它。

更实用的是，字长从此不用一步步乘生成元去试了。归并排序数逆序数是 O(nlog⁡n)O(n\log n)O(nlogn)，直接算出每个元素在第几层。写个 n=4n=4n=4 的例子，各层计数是

1, 3, 5, 6, 5, 3, 1.1,\ 3,\ 5,\ 6,\ 5,\ 3,\ 1.1, 3, 5, 6, 5, 3, 1.

24 个元素按字长分成 7 层，头尾对称，像一座金字塔。这个数列在代数里有个现成的位置，是 qqq-阶乘的系数。

▸ 1,3,5,6,5,3,1 从哪来？

把所有元素按字长归类，用一个多项式记录每一层有多少个元素：

五、三层其实是同一张图

把三次跳跃叠在一起看。闭包是 BFS 撑满凯莱图，SJT 是沿凯莱图走一条哈密顿回路，分层是凯莱图到 eee 的距离。三个视角，落在同一张图上。

下面这张还是 S₄ 的字长球，多了一条高亮的路径。这条路径就是 SJT 序列：每一步交换相邻位置，也就是右乘一个相邻对换，所以在字长球上它每一步都跨到相邻一层（字长 ±1\pm 1±1），从北极出发，沿字长上上下下铺满整座球，最后回到北极，24 个节点各走一遍。

悬停任何一个节点，能看到它的元素名。白色那根线每跨一层，就是一次相邻交换；它从不跳层，因为字长定理在管着，相邻对换永远只把逆序数改变 1。

顺带看一眼换生成集会发生什么。字长是「群加生成集」这个配对的属性，不是群自己的属性：把生成集换成全部对换 {(ij)}\{(ij)\}{(ij)}，字长变成 n−#cycles(σ)n-\#\text{cycles}(\sigma)n−#cycles(σ)，其中 #cycles\#\text{cycles}#cycles 是循环分解里循环的个数（不动点也算）。同一批元素，字长整个重排：南极的 w0=(14)(23)w_0=(14)(23)w0​=(14)(23) 在相邻对换下要走 6 步，换成全部对换只要 2 步，它自己就是两个对换的乘积；反过来，(13)(13)(13) 从 3 步缩到 1 步。再换成循环移位加一次对换，字长变成烙饼排序的次数。选中相邻对换之所以最丰富，是因为这组生成元让 SnS_nSn​ 成为一个 Coxeter 群，第六节的路牌会说它。

六、门外还有一条长廊

推到这里，这篇就该收了，不收的话会一路滑进 20 世纪的代数几何。只留四个路牌，各配一个可以自己去搜的关键词。每个路牌下面挂了一个折叠块，想多走两步再点开。

  • 弱 Bruhat 序。把「乘一个生成元且字长加一」定义成「向上一步」，这样长出来的偏序叫弱 Bruhat 序，字长是它的秩函数。这个偏序的哈斯图，就是相邻对换的凯莱图。
  • Coxeter 群。SnS_nSn​ 关于相邻对换是 A 型 Coxeter 群，字长是 Coxeter 群论的核心函数。所有最短写法都能由两条关系互相推出：辫子关系 s1s2s1=s2s1s2s_1s_2s_1=s_2s_1s_2s1​s2​s1​=s2​s1​s2​，交换关系 sisj=sjsis_is_j=s_js_isi​sj​=sj​si​（∣i−j∣≥2|i-j|\ge 2∣i−j∣≥2）。第四节 (13)(13)(13) 的两条最短写法相等，用的就是第一条。
  • 旗簇的上同调。旗簇的 Bruhat 分解按 SnS_nSn​ 的元素编号，每个胞腔的上同调维数恰好是字长。所以 ∑qℓ(w)\sum q^{\ell(w)}∑qℓ(w) 这个多项式，同时是旗簇的 Poincaré 多项式。
  • Kendall τ 距离。字长等于两个排列的 Kendall τ 距离，推荐系统和投票理论里比较两个排序的差异，用的就是这个量。
▸ 路牌一：弱序在 S₃ 上的完整样子

把「向上一步」落到 S3S_3S3​。规定 σ≤τ\sigma\le\tauσ≤τ 当且仅当能从 σ\sigmaσ 出发，每步右乘一个生成元、字长加一，走到 τ\tauτ。「每步加一」保证只走上坡，不绕路。

▸ 路牌二：两条关系怎么改写最短写法

先看两条关系的字长账。辫子关系 s1s2s1=s2s1s2s_1s_2s_1=s_2s_1s_2s1​s2​s1​=s2​s1​s2​，两边都是 3 个生成元；交换关系 sisj=sjsis_is_j=s_js_isi​sj​=sj​si​（∣i−j∣≥2|i-j|\ge 2∣i−j∣≥2，不相邻的对换互不打扰），两边都是 2 个。用它们改写一串写法，长度始终不变，变的只是写法本身。

第四节 (13)(13)(13) 的两条最短写法，靠辫子关系一步互变。交换关系在 S4S_4S4​ 里有现成的实例：(12)(34)=(34)(12)(12)(34)=(34)(12)(12)(34)=(34)(12)，引擎验证相等，因为 1、2 和 3、4 互不相邻。

Coxeter 理论进一步保证：同一个元素的所有最短写法，都靠这两条关系互相可达。所以「最短写法」不是唯一的一串符号，而是一整个等价类，字长作为「类的公共长度」因此良定义。这也解释了字长球为什么画得出来——每个元素只占一层，不管你挑哪条最短写法。

把生成元画成点，有辫子关系的连一条边，得到的图叫 Coxeter–Dynkin 图。相邻对换给 SnS_nSn​ 带来的是一条链 s1−s2−⋯−sn−1s_1-s_2-\cdots-s_{n-1}s1​−s2​−⋯−sn−1​，即 A 型图；换个生成集，图就换样，「群加生成集」的配对属性在这里再次现身。

▸ 路牌三：旗簇，字长的几何影子

旗是线性代数里的嵌套链：把复 nnn 维空间的一维子空间装进一个二维子空间，再装进三维，一直装到 n−1n-1n−1 维。n=3n=3n=3 时就是「一条直线躺在一个平面里」。让 SnS_nSn​ 交换基向量，一面旗被搬到另一面；所有旗组成的空间叫旗簇。

Bruhat 分解说，旗簇可以按 SnS_nSn​ 的元素切成 n!n!n! 块，每块用一个置换编号，块的维数恰好是编号的字长。S3S_3S3​ 的旗簇切成 6 块，维数是 0,1,2,3,2,10,1,2,3,2,10,1,2,3,2,1——又是金字塔。

更深的对应在拓扑一侧：给旗簇每个维数上数「独立的圈和洞」，汇总成一个多项式，数出来正是 [n]q![n]_q![n]q​!。同一个多项式，在代数里数排列的字长，在几何里管胞腔怎么切，在拓扑里数空间有多少洞。不用懂上同调也能感受到这里的整齐：字长这座金字塔，是三个领域共用的账本。

▸ 路牌四：Kendall τ，两份排名差多少

两个评委给同一批 4 个选手排名。甲：A>B>C>DA>B>C>DA>B>C>D；乙：B>A>D>CB>A>D>CB>A>D>C。把乙相对甲的分歧记成一个排列：甲的第 1 名 AAA 在乙那里排第 2，第 2 名 BBB 排第 1，第 3 名 CCC 排第 4，第 4 名 DDD 排第 3，得到 [2,1,4,3][2,1,4,3][2,1,4,3]。数它的逆序：只有 A,BA,BA,B 一对和 C,DC,DC,D 一对，τ 距离是 2。

[2,1,4,3][2,1,4,3][2,1,4,3] 写成循环记号就是 (12)(34)(12)(34)(12)(34)，第四节七层表第 2 层的成员。也就是说，两份排名的分歧量，直接住在本文字长球的第 2 层：给单个排列数逆序，和给两份排名算差异，是同一个动作。

完全相反的排名距离最大，(42)=6\binom{4}{2}=6(24​)=6。推荐系统比较两个用户的口味差多远、投票理论把多份排名聚合成一份（Kemeny 规则），用的都是这个距离。排序学习里把 Kendall τ 当损失函数的变体也不少。

洗牌也顺带一提。每步随机挑一对位置交换，就是凯莱图上的随机游走，多久能走到均匀分布是概率论里的专门问题。现实里的鸽尾洗牌对应另一个模型，Bayer–Diaconis 算出洗约 32log⁡2n\frac{3}{2}\log_2 n23​log2​n 次就近似均匀。两条路都靠「群加生成元」来陈述。
