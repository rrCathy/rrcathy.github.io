文中插图由 GroupViz 引擎渲染，能拖动、能悬停。十九件展品里七件是 3D 的，鼠标拖拽就能转。

怎么读这篇。 当成展馆逛，别当论证读。2D 一座厅、3D 一座厅，每间展柜放一件形状，配一段策展说明。展品顺序无关紧要，从任意一件看起都行，只有几处交叉引用会指回前面看过的展柜。

写这篇之前，我把引擎里挑形状的那段代码从头读了一遍。读之前我以为它多少有点「算法」的样子，读完发现，它大部分时候在干的事是查族谱。这个群从哪来，就给它发哪张脸。半直积来的发重布线，直积来的数因子，置换群来的直接翻多面体顶点表。

《凯莱图：从手绘到代码，再到引擎》结尾留的钩子说，形状该由边的结构推出来。引擎最后没走这条路，它顺着「群是怎么造出来的」走完了全程。这篇把两座厅的形状挨个过一遍，看看这条路线能走多远，在哪一柜开始认输。

导览：为什么分两座厅

同一个群，摊在平面上和放在立体里是两种东西，原因一半在数学，一半在代码。

平面挑图。边一多，图就交叉成一团毛线，有些凯莱图干脆塞不进平面，S₅ 的相邻对换凯莱图就不是平面图，这个证明留在 3D 厅字长球那一柜。三维没这个负担，任何有限图都能嵌进去，边不交叉。

代码这边，2D 和 3D 是两套独立的布局函数、两份形状名单，2D 十四种，3D 二十种。同一条策略逻辑落在两个维度，长出了两套名字。2D 厅的双环和 3D 厅的棱柱是同一个二面体结构，2D 厅的甜甜圈是嵌套出来的近似，3D 厅的环面才是真的几何体。

逛展须知一条，每件展品的说明里都写着它的适用条件和失效条件。形状是选出来的，选就有条件。

2D 厅

展柜一 · 环会自己扭

主展品是 21 阶的 C7⋊C3C_7\rtimes C_3C7​⋊C3​，群论里最小的 Frobenius 群之一。它的 symbol 里带着冒号，决策链在头一站就把它拦下来，交给重布线形状（引擎内部叫 rewiring）。

三个七元环是正规子群 N=C7N=C_7N=C7​ 的三份副本，环心摆在 H=C3H=C_3H=C3​ 的主环上。环内的边是「乘 bbb」，bbb 生成那个七阶环；跨环的辐条是「乘 aaa」，aaa 是三阶作用元。

对着图看，辐条是斜的。一个环到下一个环的连线拧着劲儿。

恒等元那个环按 NNN 的原样摆，另外两个环的元素被 φ\varphiφ 扭过了位置。φ(a)\varphi(a)φ(a) 把 bbb 送到 b4b^4b4，aaa 环整体转三格；φ(a2)\varphi(a^2)φ(a2) 把 bbb 送到 b2b^2b2，a2a^2a2 环转一格。三个环三种相位，全写在辐条的斜度里。

φ\varphiφ 不平凡，环就扭。扭多少由 φ(h)\varphi(h)φ(h) 说了算。

16 阶有三个群的骨架一模一样，都是「八阶正规环配一个二阶作用元」，差别全在 φ\varphiφ。引擎把它们全画成重布线，都是两个环，扭法各不相同。

QD₁₆ 把八阶旋转元扭到 a3a^3a3。同型的 C8:C2C_8:C_2C8​:C2​ 扭到 a5a^5a5，16 阶二面体扭到 a−1a^{-1}a−1。三个群画出来互不相同，连镜像都对不上。换句话说，φ\varphiφ 的差别是它们之间仅有的差别，形状把它直接画了出来。

▸ 半直积与 φ 的严格说法

群 GGG 是半直积 N⋊φHN\rtimes_\varphi HN⋊φ​H，意思是三件事：NNN 是正规子群，HHH 是子群，N∩H={e}N\cap H=\{e\}N∩H={e}，且每个元素唯一地写成 nhnhnh。乘法规则由 φ:H→Aut⁡(N)\varphi:H\to\operatorname{Aut}(N)φ:H→Aut(N) 决定：h n h−1=φ(h)(n)h\,n\,h^{-1}=\varphi(h)(n)hnh−1=φ(h)(n)。给定 N,HN,HN,H 之后，不同的 φ\varphiφ 给出不同构的 GGG，16 阶那三个群就是三个不同的 φ\varphiφ。

F₂₁ 的数字可以验算。取 aaa 为三阶元、bbb 为七阶元，引擎的乘法表给出 a2ba−2=b2a^2ba^{-2}=b^2a2ba−2=b2。设 φ(a):b↦bk\varphi(a):b\mapsto b^kφ(a):b↦bk，则 φ(a)2\varphi(a)^2φ(a)2 把 bbb 送到 bk2b^{k^2}bk2，于是 k2≡2(mod7)k^2\equiv 2\pmod 7k2≡2(mod7)，解得 k=4k=4k=4（16≡216\equiv 216≡2）。所以 φ(a)\varphi(a)φ(a) 就是 b↦b4b\mapsto b^4b↦b4，它落在 Aut⁡(C7)≅C6\operatorname{Aut}(C_7)\cong C_6Aut(C7​)≅C6​ 的那个三阶子群 {1,2,4}\{1,2,4\}{1,2,4} 里。

展柜二 · 数因子

直积群的 symbol 里有个乘号。决策链到这里先办一件事，数因子。

把 symbol 拆开，相邻同底的循环因子合并（C2×C2C_2\times C_2C2​×C2​ 并成 C22C_2^2C22​，按一个非循环因子 V4V_4V4​ 对待）。数完，按成色分。

全是循环因子，铺格点。C6×C4C_6\times C_4C6​×C4​ 拆出两个方向，一个 6 步、一个 4 步，落成 6×4 的网格。

非循环因子一进来，形状就开始弯。循环配非循环，走交错同心圆：S3×C3S_3\times C_3S3​×C3​ 每一层是一份 S3S_3S3​ 副本，就是那个凯莱六边形，层数等于 C3C_3C3​ 的阶，三层，相邻层错开半格，C3C_3C3​ 的边成了层间斜线。

两个因子都不循环，走甜甜圈。V4×S3V_4\times S_3V4​×S3​ 里谁也不当方向，引擎让一个因子做主环，另一个的副本挂在主环每个点上，挂出来的环再挂下一层。

第四件不在这三类里。C33C_3^3C33​ 三个因子全是循环群，按分类该铺格点，但它有个更贴身的结构，一个 C3C_3C3​ 做三角形环，剩下 C32C_3^2C32​ 做 3×3 网格，每个格点中心挂一整只环。这个分解是引擎用一次纯群论探测找出来的，要求唯一、因子交换，找得到才走环上网格。

▸ 因子归组的细则与一个陷阱

归组规则有两条。其一，相邻同底的循环因子合并，C4×C2×C2C_4\times C_2\times C_2C4​×C2​×C2​ 里两个 C2C_2C2​ 并成 C22C_2^2C22​，按非循环因子 V4V_4V4​ 对待。这就是有限阿贝尔群那件事（C6≅C2×C3C_6\cong C_2\times C_3C6​≅C2​×C3​，分解方式不唯一）在布局层的落地。其二，同底幂看底循环不循环：循环底保持紧凑，C22C_2^2C22​ 算一个因子；非循环底按管道段展开，S3×S3S_3\times S_3S3​×S3​ 落盘成 S32S_3^2S32​，指数 2 记作两个 S3S_3S3​，于是照样进甜甜圈展柜。

S3×C3S_3\times C_3S3​×C3​ 走交错同心圆还有个前提，非循环因子要有环状副本可用，DnD_nDn​ 的副本是双环，S3S_3S3​ 的副本是六边形。副本本身是因子自己的凯莱图，形状在因子层面已经定好了。

展柜三 · 看出身

循环群只有一个方向可走，凯莱图就是一条闭合的环。C30C_{30}C30​ 的三十个元素摆成正三十边形，边全在外沿，周期一眼可见。

菜单里还藏着一件手动展品，螺旋。元素沿阿基米德螺线铺开，逐段弧长均匀，阶数大了也不内挤外散。

我试过给 C30C_{30}C30​ 换成螺旋，好看，但盯着看半天，数不出这是个 30 阶的循环。默认形状要负责让人读出结构，三十边形的外沿比一圈螺线清楚。引擎代码里那句注释写得更直白，大循环用螺旋会显得杂乱。想看螺旋，菜单里手动切。

二面体的出身写在脸上，一半旋转一半反射。双环形状让两层各管一半：外环放旋转，正 nnn 边形，边沿圆周；内环放反射，同位角，径向成对。

展柜四 · 总得有个兜底

决策链再长也是 if 瀑布，总有群从所有分支上漏下去。漏网的也得有图，这就是兜底的职责，不一定好看，但必须有，否则渲染直接开天窗。

2D 的兜底是圆。任何群把元素摆到圆周上，图就完整，哪怕边交叉得厉害。圆之外还有一件任何群都能手动切的形状，圆锥俯视：恒等元坐中心，其余元素按阶分环，二阶元一圈、三阶元一圈，环内再按共轭类分扇区。

按阶分环是有讲究的。元素阶是任何群自带的不变量，不用探测也不会失败，兜底要的就是这个。

兜底也会翻车，而且翻得比想象中隐蔽。

引擎按 symbol 前缀给置换群发形状，S 开头就当 SnS_nSn​ 处理。这条规则便宜，代价是它不认识「S 开头的非置换群」：SL(2,3) 进来也以 S 开头，被 Sₙ 的兜底接走，落了圆形而不是圆锥。24 阶的 SL(2,3) 就这么躺在圆形里。

错误长什么样，一张 24 节点的圆，边交叉成一团，什么结构都读不出来。也不崩，就是难看。这类错误不报错、不断渲染，只是悄悄把一个群画错了地方，发现它靠的是逐个群过一遍形状、跟预期对表，不是等某个测试挂掉。

特展柜一 · 一个群一张脸

特展第一件，也是整座展馆里故事最长的一件，Q₈ 的勾股正方形。

外圈好定，{1,i,−1,−i}\{1,i,-1,-i\}{1,i,−1,−i} 是个四元环，摆成正方形，理由是对称。里面四个点 {j,k,−j,−k}\{j,k,-j,-k\}{j,k,−j,−k} 来回调位置，调出一个歪的正方形，摆完一看，这张图是勾股定理的证明图。直角在 −k-k−k，一条直角边从 −k-k−k 连到 iii，另一条从 −k-k−k 连到 111，方向向量 (3,1)(3,1)(3,1) 与 (1,−3)(1,-3)(1,−3)，点积为零。量长度，短边比长边一比三，斜边 1→i1\to i1→i 是短边的根十：12+32=(10)21^2+3^2=(\sqrt{10})^212+32=(10​)2。中间那个 jjj 落在长腿上，把长腿分成二比一。

形状先出现，定理是后认出来的。

第二件略讲。置换群在 2D 的默认形状是三维多面体的等轴投影，S4S_4S4​ 的 24 个元素落进截角八面体的顶点，压扁成平面图，节点成对叠在一起。

多面体顶点表的故事《凯莱图：从手绘到代码，再到引擎》讲全了，A₄ 的截角四面体怎么手绘、怎么固化成查表。S₃ 的六边形也是老朋友，环序是人眼挑的，不重复展出。

3D 厅

过一道门，同一套策略换了一批名字。约束也从平面性换成了视觉：什么都能画，但要看得出结构。

展柜六 · 环摞起来

半直积在 3D 走圆柱。Q16Q_{16}Q16​ 的四个 ⟨b⟩\langle b\rangle⟨b⟩ 陪集环沿竖直方向摞起来，每层四只节点，层内 bbb 边走弧，层间 aaa 边走竖直直线。这张是对齐 Group Explorer 的圆柱画的。

和 2D 第一柜是同一件事的两种摆法，陪集结构没变。2D 把环平铺在主环上，看 φ\varphiφ 怎么扭；3D 把环摞起来，看层与层之间的竖直连接。想读扭转去 2D，想读陪集分层来 3D。

展柜七 · 真几何

直积在 3D 厅的待遇明显更好，因子不用再靠嵌套和交错来模拟，积几何直接存在。

S3×C3S_3\times C_3S3​×C3​ 的圆柱，循环因子沿轴分成三层，每层铺一份 S3S_3S3​ 副本环。回看 2D 厅第二柜那张交错同心圆，它就是这座圆柱的正俯视图。层间错半格，俯视图里看是交错，立体图里看是螺旋上升的斜边。

V4×S3V_4\times S_3V4​×S3​ 的环面是本柜主展品。2D 厅的甜甜圈是嵌套出来的近似，这里的环面是真的：主轴环张在水平面上，每个点挂一只竖直小环，两组因子各占一个方向。

全循环的 C6×C4C_6\times C_4C6​×C4​ 在 3D 里铺成格架，24 只节点进三维格子。逻辑和 2D 格点一样，只是格子从平面换到了立体。

展柜八 · 棱柱

双环的 3D 化身是棱柱。D6D_6D6​ 的旋转元摆下层六边形，反射元摆上层，同位角对齐，反射边竖直连过去。

2D 双环读出来的是两层身份不同。3D 棱柱多给一样东西，几何。上下两环加竖直边是一只真实的六棱柱，二面体的对称性在几何体上直接可读。

展柜九 · 圆后面还有一层

3D 的兜底链比 2D 长一节。循环群和阿贝尔群拿圆环，其余无名之辈落圆锥，元素沿竖直方向按阶分层。再往下还有一层很少露面的：布局函数万一算不出坐标，退回斐波那契球面，节点均匀铺在球壳上。连兜底的兜底都是均匀的。

特展柜二 · 球、立方体、超立方体

第一组不设单独展柜。多面体布局的机制《凯莱图：从手绘到代码，再到引擎》有整节详文，A₄ 拿截角四面体、S₄ 拿截角八面体、A₅ 拿截角二十面体，顶点表固化在引擎里，投影到平面就是 2D 厅那张 S4S_4S4​。

主展品是字长球。这个形状只对 S4S_4S4​ 和 S5S_5S5​ 存在，生成元限定为相邻对换。它也是全馆唯一一件由边结构决定的默认形状。

每个置换有个字长：从恒等出发，最少乘几次相邻对换能变出它，字长就是逆序数。字长相同的元素铺在同一层纬圈上，S5S_5S5​ 的 120 个元素铺成 11 层，分布是 1, 4, 9, 15, 20, 22, 20, 15, 9, 4, 1。北极是恒等元，南极是逆序最长的那个置换。相邻对换让字长加减一，每条边都连接上下两层，层内一条边都没有。四个生成元各占一个方位瓣，从北极出发的四条边指向四个方向，整座球的经线大致沿这四个瓣流动。

S4S_4S4​ 的字长球七层，1, 3, 5, 6, 5, 3, 1，《从全排列到 Sₙ：三次跳跃》展过两张。S5S_5S5​ 这张是新的，难度和 S4S_4S4​ 不在一个量级。

这张图的开发过程还有一段插曲。前后让 agent 搓了十个小时，布局的各种约束怎么都摆不平，晚上休息，换手机上的智谱清言聊了两轮，出来了。把成品代码拿回来返给 agent，让它照着收尾。

▸ S₅ 的字长球为什么难：一个平面性矛盾

S5S_5S5​ 的相邻对换凯莱图不是平面图，三行就能证。字长分奇偶，相邻对换改变奇偶性，所以图是二部图。二部图没有奇圈，平面图上界给出面数 F≤E/2F\le E/2F≤E/2；图的 V=120V=120V=120，每个元素连四条边，E=240E=240E=240，于是 F≤120F\le 120F≤120。可欧拉公式要求 F=V−E+FF=V-E+FF=V−E+F 解出 F=2−120+240=122F=2-120+240=122F=2−120+240=122。122 大于 120，矛盾。

矛盾落到现实上，固定纬度平面加直线边，这张图必然有视觉交叠，纸面上无解。引擎的对策是松弛，节点之间加斥力、边与边之间做线段距离斥力把交叠错开、角度弱锚定保住方位结构、最后把外圈节点吸附回球面。你看到的这张图，是一张数学上必然交叉的图在三维里尽力错开的结果。

Q₈ 的 3D 化身是立方体，八个元素落八个顶点。2D 那张勾股正方形是平面上的证明图，立方体是同一个群的立体版本。

最后一件留给 C24C_2^4C24​。十六个元素全是二阶元，四个独立方向各走一步，正好是四维超立方体的顶点结构。引擎把 16 只节点按位基分进两个立方体，内外同心投影，外层第零分量，内层第一分量，连线就是超立方体的边。

低一阶的 C23C_2^3C23​ 在 2D 是双环、在 3D 是立方体。从 C24C_2^4C24​ 再往上，直观就只能靠投影了，四维的东西在三维里留不下完整的像。

出口

《凯莱图：从手绘到代码，再到引擎》结尾问的是，能不能让布局算法读边表、认结构，从「谁和谁相连」反推出形状。走完这两座厅，答案已经清楚了。

引擎没走那条路。它的办法是查族谱，从 symbol 往下逐条判断，命中即返回。

冒号交给重布线和圆柱，乘号交给因子分析和积几何，出身交给族类和特展，族谱查不到的交给兜底。群的构造方式本身就携带骨架信息，半直积自带陪集分层，直积自带因子方向。读构造比读边便宜得多。

便宜在哪，值得说清楚。「读边认图」要做的是两件事，判断一张图同构于哪个已知布局，或者现场算出一个好的嵌入。图的同构判定到今天也没有便宜的通用解法，这是它贵的根源。

字长球是唯一的例外，它是真的在读边，字长就是到北极的边数。它能这么做靠的是「生成元限定为相邻对换」这个窄条件，分层结构不用猜，算逆序数就有。代价是只为两个群服务。通用版的「认图」没有便宜解法，这条便宜的路线就顶上了，链上每一层都有数学理由，多数时候够用。

下一次在引擎里换个群，形状跟着变，背后就是这条链在走。形状从群的构造方式里读出来。构造信息缺页的时候，才轮到圆和圆锥顶上。
