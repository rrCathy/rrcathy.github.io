怎么读这篇。 这是一篇技术文，主角是 1936 年的 Todd-Coxeter 陪集枚举算法。主线只需要三个动作，走环、补格、合并；证明收在第五节，完整代码在第四节，赶时间可以在任何一层停下。第二节用 S3S_3S3​ 把一张两行的小表从零造出来，第三节造一张更大的，中途撞上一次碰撞。

给一个群，最省事的定义方式是生成元加关系。三条等式

a2=e,b3=e,(ab)3=ea^2 = e,\qquad b^3 = e,\qquad (ab)^3 = ea2=e,b3=e,(ab)3=e

连同生成元 a,ba,ba,b 一起，记作 ⟨a,b∣a2, b3, (ab)3⟩\langle a, b \mid a^2,\ b^3,\ (ab)^3 \rangle⟨a,b∣a2, b3, (ab)3⟩。这个记号承诺的事情很有限。凡是由满足这三条等式的元素生成的群，都是它的同态像。至于它自己有多少元素，是不是有限群，记号本身一个字都没说。

把这三条关系喂给 Todd-Coxeter 算法，几轮之内它会交出一张四行四列的表，顺带回答上面的问题。这个群有 12 个元素，是正四面体的旋转群 A4A_4A4​。1936 年 Todd 在曼彻斯特做这件事的时候，演算纸是旧墙纸的背面，Coxeter 后来回忆他一小时能处理两百个陪集。这篇把整个流程走一遍：规则、手算、代码、证明，以及它后来长成了什么。

一、语法有了，语义欠着

生成元和关系这套记法，经济性极好。描述 S3S_3S3​ 只需要两个字母和三条等式，描述 60 阶的 A5A_5A5​ 也只需要三条（第五节会见到）。代价写在价格标签背面。记号给的是语法；语义要自己算。

拿 S3S_3S3​ 做练习场。取 a=(12)a = (12)a=(12)，b=(123)b = (123)b=(123)，逐条验算，a2=ea^2 = ea2=e，b3=eb^3 = eb3=e，而 ab=(23)ab = (23)ab=(23) 自乘回到 eee。三条全部成立。这份验算的用处在于，两个置换可以充当表现里 a,ba, ba,b 的一份翻译：表现要求的每条等式，翻译过去都真实成立，于是表现里推得动的等式，翻译过来条条成立，表现永远推不翻自己的任何一个像（这件事的正式名字是万有性质，收在下面的折叠块）。所以 ⟨a,b∣a2, b3, (ab)2⟩\langle a, b \mid a^2,\ b^3,\ (ab)^2 \rangle⟨a,b∣a2, b3, (ab)2⟩ 必定打得出 S3S_3S3​ 这个像。翻译管不了另一半：它自己有多大。它可以是 S3S_3S3​，也可以是个更大的、以 S3S_3S3​ 为像的群，记号看不出来，得算。

▸ 万有性质：表现的身价所在

表现 ⟨S∣R⟩\langle S \mid R \rangle⟨S∣R⟩ 的定义是一条泛性质。在所有由 SSS 生成且满足 RRR 的群里，它是最「自由」的一个：别的群满足的等式它全满足，它满足的等式别的群未必满足。推论是，从 RRR 出发能推出来的每条等式，在任何一份满足 RRR 的具体解释里都成立。所以一份翻译只能保证表现不小于像，永远不能证明表现就等于像，后者正是 Todd-Coxeter 要干的活。

这一条也是第五节证明的地基。只要表能给出「一组满足全部关系的置换」，表现到这些置换的同态就免费到手。

Todd 和 Coxeter 的想法是不去数元素，改数陪集。子群 HHH 把群切成若干份，数份数往往比数元素容易得多，因为 HHH 自己的规模常常直接写在关系里（比如由一个 b3=eb^3 = eb3=e 的元素生成，就至多三个元素）。下一节把这个思路在 S3S_3S3​ 上走完整。

二、陪集表：把群作用写在纸上

直接动手算。把 S3S_3S3​ 的六个元素摆上桌，生成元照第一节取 a=(12)a = (12)a=(12)，b=(123)b = (123)b=(123)，子群取 H=⟨b⟩={e, b, b2}H = \langle b \rangle = \{e,\ b,\ b^2\}H=⟨b⟩={e, b, b2}，三个偶置换。

第一步，从 HHH 出发，把每个成员右乘 aaa，看落到哪些元素：

ea=a,ba=(13),b2a=(23).ea = a,\qquad ba = (13),\qquad b^2a = (23).ea=a,ba=(13),b2a=(23).

落进的是三个对换，恰好是桌上剩下的另一半。这样 S3S_3S3​ 分成了两份，没有重叠没有遗漏。这样的每一份叫 HHH 的一个右陪集：把 HHH 整体右乘某个元素得到的那组元素。陪集的名字按来历起：一份就是 HHH 本身；另一份是 HHH 的成员逐个右乘 aaa 得到的，叫 HaHaHa——名字里的字母从左往右读，就是从 HHH 走到它的那串右乘。

第二步，把右乘的落点填成表。四格，每格都是一组元素逐个右乘。HaHaHa 右乘 aaa：aa=eaa = eaa=e，(13)a=b(13)a = b(13)a=b，(23)a=b2(23)a = b^2(23)a=b2，全部落回 HHH，a2=ea^2 = ea2=e 让两个 aaa 抵消。HHH 右乘 bbb：bbb 本来就在 HHH 里，原地。HaHaHa 右乘 bbb：(12)b=(23)(12)b = (23)(12)b=(23)，(13)b=(12)(13)b = (12)(13)b=(12)，(23)b=(13)(23)b = (13)(23)b=(13)，转来转去不出对换这份。四个格子凑齐：

这张表怎么读，一句话：陪集 HHH 里的元素右乘 aaa，整个跳进陪集 HaHaHa；右乘 bbb，原地不动。同一份里的元素共享落点，所以格子里填的是陪集的名字，不必管具体是哪个元素。名字还自带验算：(Ha,a)=H(Ha, a) = H(Ha,a)=H 读出来就是 Ha⋅a=HHa \cdot a = HHa⋅a=H，右乘 aaa 两步抵消。每个生成元还配一列逆元（a−1,b−1a^{-1}, b^{-1}a−1,b−1 下面记作 A,BA, BA,B），表里省画，它们由配对规则自动决定：(Ha,a)=H(Ha, a) = H(Ha,a)=H 必然伴随 (H,A)=Ha(H, A) = Ha(H,A)=Ha。

从这张表里直接读出三件事。一，S3S_3S3​ 被 HHH 切成两份，指数 [G:H]=2[G:H] = 2[G:H]=2。二，右乘 aaa 交换两个陪集，右乘 bbb 让两个陪集都原地——⟨b⟩=A3\langle b \rangle = A_3⟨b⟩=A3​ 是 S3S_3S3​ 的正规子群，两个陪集构成商群 C2C_2C2​，bbb 在商群里是单位元，表把商群都画出来了。三，HHH 若取平凡子群，每份只有一个元素，数份就是数全部元素。第五节证明一件更强的事：对任何表现，只要表填满且检查全部通过，份数就恰为指数。

Todd-Coxeter 做的就是这个计数：不偷看答案，光凭生成元和关系，把一个表现里子群的陪集份数数出来。真到手一个表现，陪集有几份、每份装哪些元素，事先一概不知，表要从空表造起。做法是把刚才的手算归纳成三条规则、三个动作。

规则，一张合格的陪集表必须同时满足：

  1. 每条关系词（aaaaaa、abababababab 这样的词）从任何陪集出发走一圈，回到出发的陪集——关系在群里是恒等式，作用到哪个陪集上都成立；
  2. 每个子群生成元从 HHH 出发走一圈，回到 HHH——H⋅h=HH \cdot h = HH⋅h=H；
  3. 逆元列配对成立——右乘 xxx 再右乘 x−1x^{-1}x−1 原地踏步。

动作，把不合格的半成品打磨到合格：

  • 走环。拿一个词沿表走，能走完就检查终点对不对。
  • 补格。走到没填的格子，开一个新陪集，把环闭上。
  • 合并。同一个格子被两条路给出两个不同的落点，说明这两个名字其实是同一个陪集，合并，全部改写。

把 S3S_3S3​ 从空表重走一遍，验证这套流程给得出刚才那张表。开 HHH。子群生成元 bbb 从 HHH 走环，H⋅b=HH \cdot b = HH⋅b=H，格子 (H,b)(H, b)(H,b) 填 HHH。关系 aaaaaa 从 HHH 走，(H,a)(H, a)(H,a) 没填，开新陪集 HaHaHa 填上，第二个 aaa 走回 HHH。关系 abababababab 从 HHH 走，aaa 到 HaHaHa，(Ha,b)(Ha, b)(Ha,b) 没填。开新陪集之前先看一眼终点：从终点 HHH 倒着走（沿逆元列），倒退 bbb 还在 HHH（bbb 是自环），再倒退 aaa 到 HaHaHa。倒走停下的地方恰好就是断边所在，中间没有空档，(Ha,b)(Ha, b)(Ha,b) 直接填 HaHaHa，一个新陪集都不用开。剩余扫描从两个陪集各走一遍，全部闭合，表就是上面那张。一次碰撞都没有。

同一个 S3S_3S3​，从 6 个元素压到 2 个陪集，凯莱图上的六个点折成两个。下一节的主角 A4A_4A4​ 会再压一次，12 折成 4，而且这一次，算法中途会出事。

▸ 为什么子群生成元只从 H 扫

关系词从每个陪集扫，子群生成元只从 HHH 扫，这个不对称是实现里最容易写错的地方。

理由在陪集的代数里。关系词 rrr 在 GGG 里等于 eee，所以 (Hg)⋅r=Hgr=Hg(Hg) \cdot r = Hgr = Hg(Hg)⋅r=Hgr=Hg，对每个陪集都成立，从任何陪集扫都该闭合。子群生成元 hhh 只保证 H⋅h=HH \cdot h = HH⋅h=H；换一个陪集，(Hg)⋅h=H(gh)(Hg) \cdot h = H(gh)(Hg)⋅h=H(gh)，要它回到 HgHgHg 得有 ghg−1∈Hghg^{-1} \in Hghg−1∈H，一般不成立。

A4A_4A4​ 里就有现成的反例。h=b=(234)h = b = (234)h=b=(234)，取 g=a=(12)(34)g = a = (12)(34)g=a=(12)(34)，共轭 ghg−1=(a(2) a(3) a(4))=(1 4 3)ghg^{-1} = (a(2)\ a(3)\ a(4)) = (1\ 4\ 3)ghg−1=(a(2) a(3) a(4))=(1 4 3)，不在 H={e,(234),(243)}H = \{e, (234), (243)\}H={e,(234),(243)} 里。要是强行从陪集 HaHaHa 也扫 bbb，等于把一条假等式写进表里，合并会一路错下去，最后交出一张比真指数还小的表。

四、从表格到代码

手算的三条操作，翻成代码是一百行以内的事。三个数据结构：table 用字典存稀疏的陪集表，键是（陪集编号，生成元字母）——正文里陪集叫 HHH, HaHaHa, HabHabHab，代码里用整数编号当替身，编号按创建顺序发，与陪集名字一一对应——顺序和名字长短没有关系；union 是并查集，管碰撞合并；主循环负责「扫描，出碰撞就合并重来，无碰撞就补全」。倒着走的那个细节在 scan 的后半段。

def todd_coxeter(relators, subgens, gens="ab", max_cosets=300):
    gens = list(gens)
    letters = gens + [INV[c] for c in gens]
    table = {}                    # (编号, 字母) -> 编号
    union = {}                    # 并查集，碰撞合并用
    nxt = 2                       # 下一个新编号（1 = H）

    def find(i):
        while union.get(i, i) != i:
            i = union[i]
        return i

    def define(i, x, j):          # 配对定义：(i,x)=j 蕴含 (j,x^-1)=i
        table[i, x] = j
        if (j, INV[x]) not in table:
            table[j, INV[x]] = i
            return None
        # 配对槽已被占：真值强制 i 与旧值同行，交碰撞
        # （第五节「定义不说谎」在代码里的落点）
        return None if table[j, INV[x]] == i else (i, table[j, INV[x]])

    def new_coset():
        nonlocal nxt
        if nxt > max_cosets:
            raise OverflowError
        nxt += 1
        return nxt - 1

    def scan(s, word):            # 要求：s 沿 word 走一圈回到 s
        cur, k = s, 0             # 前向：能走就走
        while k < len(word) and (cur, word[k]) in table:
            cur = table[cur, word[k]]
            k += 1
        if k == len(word):
            return None if cur == s else (cur, s)
        q, m = s, len(word)       # 后向：从 s 逆着走
        while m > k and (q, INV[word[m-1]]) in table:
            q = table[q, INV[word[m-1]]]
            m -= 1
        if m == k:                # 断口两端必须同行；find 对不上即碰撞
            return None if find(cur) == find(q) else (cur, q)
        for t in range(k, m):     # 中间补新编号，把环闭上
            c = q if t == m - 1 else new_coset()
            bad = define(cur, word[t], c)
            if bad:
                return bad
            cur = c
        return None

    def merge(p, q):              # 把 q 并进 p（小号优先），传播冲突
        dq, moved = deque([(p, q)]), False
        while dq:
            a, b = dq.popleft()
            ra, rb = find(a), find(b)
            if ra == rb:
                continue
            if ra > rb:
                ra, rb = rb, ra
            union[rb] = ra
            moved = True
            for x in letters:
                va = table.get((ra, x))
                vb = table.pop((rb, x), None)
                if vb is None:
                    continue
                if va is None:
                    table[ra, x] = vb
                elif va != vb:
                    dq.append((va, vb))
        if moved:                 # 指向死编号的值重映射；整表扫一遍，教学版不优化
            for key in list(table):
                table[key] = find(table[key])
        return moved

    try:
        while True:
            moved = False
            for h in subgens:              # 子群生成元只扫 1 号
                bad = scan(1, h)
                if bad:
                    moved = merge(*bad) or moved
                    break
            if not moved:
                for i in range(1, nxt):    # 关系词扫每个编号
                    if find(i) != i:
                        continue
                    for r in relators:
                        bad = scan(i, r)
                        if bad:
                            moved = merge(*bad) or moved
                            break
                    if moved:
                        break
            if moved:
                continue
            full = True                    # 无碰撞：补全缺失条目
            for i in range(1, nxt):
                if find(i) != i:
                    continue
                for x in gens:
                    if (i, x) not in table:
                        j = new_coset()
                        table[i, x], table[j, INV[x]] = j, i
                        full = False
            if full:
                rows = [i for i in range(1, nxt) if find(i) == i]
                return len(rows), rows
    except OverflowError:
        return None, nxt - 1

for rels, subs in [(["aa", "bbb", "abab"], ["b"]),        # S3, H=<b>
                   (["aa", "bbb", "ababab"], ["b"]),      # A4, H=<b>
                   (["aa", "bbb", "ababababab"], ["b"]),  # A5, H=<b>
                   (["aaaa", "bbAA", "Baba"], [])]:       # Q8, H={e}
    print(todd_coxeter(rels, subs)[0])
print(todd_coxeter(["abAB"], ["a"], max_cosets=120)[0])   # Z2, H=<a>

前三行是热身和正戏的答案，S3S_3S3​ 指数 2，A4A_4A4​ 指数 4。第四行换了个更大的猎物：⟨a,b∣a2, b3, (ab)5⟩\langle a, b \mid a^2,\ b^3,\ (ab)^5 \rangle⟨a,b∣a2, b3, (ab)5⟩ 配 H=⟨b⟩H = \langle b \rangleH=⟨b⟩，指数 20。A5A_5A5​ 的陪集名字要拼到五个字母，从这一行起改用编号叙述。这一局不是 A4A_4A4​ 那种一次碰撞就收尾的干净仗，是十一轮的拉锯，带日志的版本记下了每一轮启程时的存活陪集数。「补 nnn」指这一轮开出 nnn 个新陪集，「并 nnn」指合并掉 nnn 个：

A4A_4A4​ 的碰撞是「多开一行、立刻回收」，A5A_5A5​ 的行数则是先暴涨后压缩的潮汐，第 5 轮冲到 22，之后被九次碰撞一路压回 20。全程 84 条边、9 次碰撞、11 轮，数字全部来自随文代码的日志。九次碰撞里五次属于两端对不上，表看上去已经很满，两条路一碰才现出原形；其余四次是走完一圈终点不对。第五行 Q8Q_8Q8​ 用的是空子群，HHH 就是平凡子群，此时表退化成群的凯莱图（正则作用），陪集个数直接就是群的阶：8。

最后一行的 None 值得单独说。⟨a,b∣abA⋅B⟩\langle a, b \mid abA \cdot B \rangle⟨a,b∣abA⋅B⟩ 也就是 ab=baab = baab=ba 的 Z2\mathbb{Z}^2Z2，子群 ⟨a⟩\langle a \rangle⟨a⟩，陪集 HbnH b^nHbn 有无穷多个。脚本冲到 120 个陪集的上限也没闭合，返回 None。这就是 Todd-Coxeter 的边界：它是半可判定的。指数有限，算法必停且答案正确；指数无穷，它只能永远跑下去。你能等到的结局只有两种，闭合，或者一直等。

五、为什么是对的

算法停下来的那张表，凭什么就是答案。定理分两半：表给出一个货真价实的群作用（于是陪集个数不超过指数），以及每个真陪集都有陪集代表（于是陪集个数不少于指数）。两头一夹，陪集个数等于指数。

前一半：表是一个真实的作用，所以 n≤[G:H]n \le [G:H]n≤[G:H]。 表填满时，每一列都是陪集集合上的置换（配对规则保证逆元列就是逆置换）。每条关系词从任何陪集走回原陪集，翻译过来是每个关系词对应的置换都等于恒等。按万有性质（第一节的 Tip），生成元到这些列置换的指派延拓成同态

ρ:G→Sn.\rho : G \to S_n .ρ:G→Sn​.

HHH 的轨道是全部 nnn 个陪集，每个新陪集都由已有陪集补出，从 HHH 总有词能走到任何陪集，作用传递。子群生成元从 HHH 闭合，加上它们生成 HHH，得 HHH 整体固定基点陪集 HHH，装在它的稳定子里。轨道-稳定子定理给出

n=[G:Stab(H)]≤[G:H].n = [G : \mathrm{Stab}(H)] \le [G : H] .n=[G:Stab(H)]≤[G:H].

后一半：定义不说谎，所以 n≥[G:H]n \ge [G:H]n≥[G:H]。 陪集的名字本身就是定义词：HabHabHab 的定义词是 ababab，从 HHH 走到它用的那串右乘。盯住一个不变量：表里每条已填的边，落点陪集的名字与真陪集等式一致——格子 (u,x)(u, x)(u,x) 填 vvv，就有真等式 u⋅x=vu \cdot x = vu⋅x=v。开新陪集时按构造成立（新名字 vvv 就是 uuu 拼上 xxx）；碰撞合并只在真等值时发生，扫描逼出的两个名字，在真陪集的作用下本来就该相同，合并后所有改写的边把等式沿表传递。归纳下来，从 HHH 沿任何词 www 走到的陪集都满足 H⋅wH \cdot wH⋅w 就是它。于是每个真陪集 HwH wHw 都有名字代表，表上的名字个数至少和真实份数一样多。

[G:H]≤n≤[G:H].[G:H] \le n \le [G:H] .[G:H]≤n≤[G:H].

两个不等式夹死，n=[G:H]n = [G:H]n=[G:H]，表就是答案。终止性另有一说。碰撞一次至少吃掉一个陪集，只吃不吐，轻松的一半在这里；麻烦的一半在证明定义不会永远跑在碰撞前面，那要给扫描顺序定一个公平性条件（每个扫描机会都反复轮到）再对轮数归纳，完整的论证偏技术，Holt 的《Handbook of Computational Group Theory》第五章有全套。指数无穷时上一节的 Z2\mathbb{Z}^2Z2 已经演示过它永不闭合。

▸ 1936 年的论文，和迟到 28 年的证明

Todd 与 Coxeter 1936 年在《Proceedings of the Edinburgh Mathematical Society》上发表了这套流程，题为 A practical method for enumerating cosets of a finite abstract group。论文的例子算到了 576 阶的群（正 24 胞体的旋转群），但通篇没有完整的正确性证明，终止性与正确性的首个形式证明要到 1964 年，由 Mendelsohn 在 Canadian Journal of Mathematics 上给出。

流程本身差点没能问世，几位审稿人没认出它的重要性，发表颇费周章。六十年代它等来了计算机。Felsch 在 1961 年、Leech 在 1963 年、Trotter 在 1964 年各自写出程序，Leech 的那篇综述里记录了当时已知的各种实现。今天它仍是计算群论里最常用的引擎之一，GAP 每次算指数、构商群，背后转的多半就是它。

六、门外长廊

三个路牌。

两大策略家族。 本文的实现属于 HLT 风格，得名于 Haselgrove、Leech 和 Trotter 五六十年代的工作，特点是猛开新陪集、事后用碰撞收割。另一家是 Felsch 风格，每开一条边就地做扫描，陪集个数压得更紧、单步更贵。两者的取舍至今是活跃的工程话题，现行最强实现之一是 Havas 和 Ramsay 的 ACE，GAP 以扩展包的形式挂它。表现换一种等价写法，运行时间可能差出一个数量级，这是用这套算法的人都要交的学费。

低指数子群。 把碰撞机制反着用。给定 HHH 数陪集是正向；反过来，把指数不超过 nnn 的所有子群一次枚举干净。Sims 在七十年代据此做出低指数子群算法，GAP 里的 LowIndexSubgroupsFpGroup 一条命令就能列出某表现全部指数 30 以内的子群。找单群、证某群没有小指数子群，用的都是它。

姊妹算法与几何读法。 Knuth-Bendix 补全走的是另一条路，把生成元上的词重写成规范形，有时能对无穷群解决字问题，这是 Todd-Coxeter 做不到的。而在几何那边，陪集表有一个覆叠空间的读法：表是覆叠图的顶点目录，补格是铺开覆叠，合并是粘合；表闭合意味着这张图只有有限个顶点，翻译回去就是指数有限。自由群的情形最干净，HHH 的 Schreier 图本身就是那张覆叠，Stallings 的折叠算法把这层几何做成了独立工具，几张图几次折叠就能判两个子群是否同在水下。

回望开头，算法的全部动作就是三下：走环、补格、合并。Todd 在墙纸背面一小时两百个陪集；今天同一套流程在笔记本上一秒能过几十万个，翻了六七个数量级，规则一个字没改。计算数学里能这样穿越九十年的东西不多，而它最初要回答的问题朴素得很：几条等式里，到底住着多少元素。
