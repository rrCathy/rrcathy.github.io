GroupViz

群论可视化

在网页中创建并交互式探索有限群。支持 Cayley 图、子群格、陪集条、同态动画、直积/半直积构造、对称群可视化与第一同构定理演示。

React TypeScript Three.js WebGL

Grouplo

群一把 · 猜群游戏

类似 Wordle 的群论猜谜游戏。根据群属性反馈（阶、交换性、幂零性、Sylow 型等），在限时内猜出目标群。三种难度，覆盖上百个常见有限群。

React TypeScript Wordle-like
